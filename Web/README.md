# Web

Folder này dùng để quản lý các ghi chú liên quan đến website **ZaloPay UI Hub**.

Gợi ý cách dùng:

- Mỗi task nên có một branch riêng.
- Ghi chú task, link Pull Request, hoặc quyết định review có thể đặt trong folder này.
- Không sửa trực tiếp branch `main` nếu chưa review.

Ví dụ tên branch:

```text
feature/update-login-page
feature/add-principle-content
fix/mobile-sidebar
```
