# Web/Landing

Landing của Zalopay UI Hub hiện được định nghĩa tại section `#introduction`
trên web chính.

Local preview:

```text
http://127.0.0.1:5173/#introduction
```

Mục tiêu:

- Dùng section Introduction làm điểm vào của web.
- Giữ Landing trong cùng luồng nội dung UI Principle hiện tại.
- Không tạo route landing riêng.
