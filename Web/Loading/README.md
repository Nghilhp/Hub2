# Loading

Folder này dùng để quản lý ghi chú, task, node id, và review liên quan đến **Loading page**.

Gợi ý file có thể tạo thêm:

```text
loading-layout.md
loading-copy.md
loading-mobile-review.md
```

Nếu có Figma node id, đặt tên file theo dạng:

```text
<node-id>-loading-page.md
```

Ví dụ:

```text
12-345-loading-page.md
```
